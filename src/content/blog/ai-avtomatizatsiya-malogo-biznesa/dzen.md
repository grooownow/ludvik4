# Какие задачи малого бизнеса можно автоматизировать с помощью AI

AI полезен не только для генерации текстов. Он может выполнять небольшие
операции внутри обычного рабочего процесса.

Например:

- распределять обращения по темам;
- извлекать суммы, даты и реквизиты из документов;
- составлять черновики писем;
- сокращать длинные переписки;
- готовить публикации на согласование;
- собирать краткий отчёт за неделю.

При этом результат модели нельзя считать гарантированно правильным. Поэтому
важные действия должны проходить проверку человеком. Если уверенность низкая
или данные неполные, задача отправляется на ручную обработку.

Начинать лучше с одного повторяющегося сценария. Нужно определить, какие данные
поступают на вход, какой результат ожидается и как будет измеряться польза.

Не стоит сразу автоматизировать финансовые, юридические и другие решения с
высокой ценой ошибки. Также AI не исправит процесс, который сам по себе не
имеет понятных правил.

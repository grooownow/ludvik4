# GitHub Spec Kit: бесплатный инструмент, чтобы ИИ делал то, что просили

Главная сложность разработки с AI-агентами не в том, что они плохо пишут код,
а в том, что они уверенно делают не то, если задачу не проговорили. Осенью
2025 года GitHub выпустил бесплатный инструмент **Spec Kit**, который помогает
это исправить.

Что он делает: разворачивает в проекте простой процесс из шагов — сначала
принципы проекта, потом спецификация (что и зачем), план (как), задачи и
реализация. Агент идёт по шагам и сверяется со спекой, а не гадает.

Чем полезен:

- меньше переделок — агент строит записанное, а не «наугад»;
- не привязывает к одному инструменту (работает с 30+ агентами);
- бесплатный и ставится в уже существующий проект.

Есть похожий инструмент от AWS — Kiro, но это целый отдельный редактор. Суть
же не в инструменте, а в привычке фиксировать задачу до кода.

Подробный разбор: https://ludvik4.dev/blog/github-spec-kit

## Спека формы заявки (V0) — реализовано

**Путь:** свой **server action** `submitLeadAction` (`src/features/lead/`). Доставка — через
подключаемые каналы (env), почта-приёмник в коде не фигурирует.

**Поля:**

| Поле                 | Обяз. | Валидация (`lead-schema.ts`)                                     |
| -------------------- | ----- | ---------------------------------------------------------------- |
| Имя                  | нет   | ≤ 100 символов                                                   |
| Задача               | да    | 10–2000 символов                                                 |
| Как с вами связаться | да    | e-mail (regex) **или** ссылка на мессенджер / телефон (≥ 7 цифр) |
| website (honeypot)   | —     | скрытое, должно остаться пустым (заполнено → тихо роняем)        |

**Порядок в экшене:** honeypot-drop → rate-limit по IP (5/мин) → zod-валидация → Turnstile →
доставка. Вход валидируется zod до любого использования (инвариант проекта).

**Доставка (`notify.ts`):** Telegram-бот и/или Resend-email, оба через env. Успех, если хотя бы
один канал принял. Если каналов не настроено — в dev/preview форма работает, в production
заявка не роняется молча (возвращаем ошибку с просьбой написать в Telegram).

**Анти-спам / анти-абьюз:**

- Cloudflare **Turnstile** (`turnstile.ts`) — при заданном секрете; без него проверка пропускается (локал/preview), с ним невалидный токен и сетевая ошибка → отказ (fail-closed).
- **Honeypot** — поле `website`, заполнено ботом → тихий drop.
- **Rate-limit** — общий `@/lib/rate-limit`, ключ по IP.
- **DDoS** — платформенная авто-защита Vercel (Firewall), код тут ни при чём.

**Позже (Next.js):** запись заявок в БД + раздел модерации (список всех заявок, статусы) —
это добавляем поверх текущего экшена, когда дойдём до дашборда.

**Секреты для доставки/капчи:** см. `docs/site-v0-setup.md`.

## Заметки по лейауту (для Pencil)

- Одна колонка, вертикальный ритм; максимум ширины контента ~640–720px для текстовых блоков, услуги — сетка 2–3 колонки на десктопе, 1 на мобиле.
- Hero: крупный H1 (бренд), лид, подлид, одна заметная кнопка. Много воздуха.
- Услуги: карточки/плитки, иконка опциональна. Ровный ритм, без визуального шума.
- Подход: три пункта в ряд (десктоп) / стопкой (мобайл).
- «Кто за этим стоит»: узкий текстовый блок + одна ссылка. Сдержанно.
- Контакт: **форма заявки** (имя / задача / контакт + капча) + открытый Telegram-канал рядом. Почта-приёмник не показывается.
- Адаптив — обязателен: 375 / 768 / 1280. Внешние ссылки — обычные `<a href>`, внутренняя навигация по якорям (`#services` и т.п.).

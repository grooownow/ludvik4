# Услуги RU-витрины: границы и объём работ по пакетам

Источник правды для страницы «Услуги и цены» (`/uslugi`, данные —
`src/features/site/pricing-draft.ts`). Обновлено: 2026-10-26.
Цены лендинга и сайтов утверждены владелицей.

## Чем отличаются услуги

|                    | Лендинг                                                    | Сайт                                                                               | Веб-приложение                                                         |
| ------------------ | ---------------------------------------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Что это**        | Одна страница                                              | Несколько страниц                                                                  | Сервис, в котором пользователь что-то делает                           |
| **Задача**         | Одно предложение → одно действие (заявка, покупка, запись) | Рассказать о бизнесе целиком: услуги, работы, цены, контакты                       | Работа с данными: личные кабинеты, расчёты, заказы, роли               |
| **Когда выбирать** | Акция, событие, запуск продукта, реклама, проверка идеи    | Бизнес с несколькими услугами или аудиториями, нужен поиск по разным запросам      | Нужна логика: аккаунты, база данных, оплаты внутри сервиса, интеграции |
| **Поиск**          | Под один набор запросов                                    | Отдельная страница под каждую услугу и частый вопрос                               | Обычно не главное: им пользуются, а не находят                         |
| **Обновление**     | Редко, правки через нас                                    | Часто: в Расширенном и выше — панель управления                                    | Постоянное развитие по задачам                                         |
| **Где граница**    | Больше одного предложения или раздела → сайт               | Появляются аккаунты, личные данные пользователей, сложные расчёты → веб-приложение | Нужна только витрина без логики → сайт                                 |

**Админка — это сайт, кабинеты — приложение.** Панель, где владелец сам
меняет тексты, цены, фото, публикует работы или новости, — обычный сайт
(Расширенный и выше). Приложение начинается, когда учётные записи и данные
появляются у посетителей: личные кабинеты, история заказов, расчёты, роли.
Ресторан: меню + форма брони/заказа — сайт; корзина, оплата, статусы
заказа и экран кухни — ближе к приложению.

Примеры сайтов на вкладке («Например»): компания или студия · портфолио
автора · ресторан или кафе · мастер или специалист ·
школа, секция или клуб · небольшой онлайн-магазин.

На вкладке «Сайты» стоят подсказки со ссылками: «Нужна одна страница…?
→ Лендинги», «Нужны личные кабинеты…? → Веб-приложения».

## Общее для всех пакетов

Исходный код · Файлы дизайна с гайдом по стилю · Размещение на хостинге и
публикация · Замер скорости · Работа по договору. Домен и хостинг
оплачиваются отдельно.

Понятия:

- **Вариант первого экрана / главной страницы** — исполнение одной идеи
  по брифу: отличаются композицией, акцентами, шрифтами, оттенками.
- **Направление дизайна** — разные образы бренда до начала дизайна
  (мудборд, палитра, шрифты, настроение) на основе анализа конкурентов и
  аудитории; клиент выбирает направление, в нём делается дизайн.
- **Гайд по стилю** — палитра, шрифты, размеры, отступы, скругления.
- **Раунд правок** — один собранный список правок; исправление ошибок
  раундом не считается (в пакетах раунды больше не перечисляются, правило —
  для договора).
- **Поддержка** — бесплатное исправление ошибок 1 / 2 / 3 месяца.
- **152-ФЗ** — согласие на обработку данных появляется вместе с формой
  (Расширенный); согласие на cookies — вместе с аналитикой поведения
  (Максимальный). Формулировки показать юристу.

## Анимации (пакеты пересобраны 2026-10-27; цены утверждены владелицей)

роликов для соцсетей. Лестница: лёгкая анимация страницы → одна

Во всех пакетах: подключение к сайту (в том числе Tilda), превью движения до разработки, исходный код, отчёт о скорости, проверка в браузерах. Согласие на cookies убрано (владелица, 2026-10-27). Маскот в пакеты не входит — персонаж по отдельной оценке. Вкладка переименована в «Анимации»: 3D-модели и конфигураторы — по отдельной оценке.

Идеи WebGL для Расширенного: «жидкий» фон / водичка, частицы, собирающиеся
в логотип, стеклянная капля-линза за курсором, шёлковый градиент, «желейный»
объект, маскот (в проекте есть шейдеры silk, glass-lens, jelly, cursor-drop).
Отдельно: платные шрифты и музыка; 3D-модели и конфигураторы — по
отдельной оценке. Примеры: живой первый экран (ссылка на Людвика) ·
страница-история · живой фон · анимированная инфографика · промо к запуску ·
микроанимации.

**Галерея «Потрогайте сами» (2026-10-27):** 6 живых плиток на вкладке —
лёгкая анимация блоков (Базовый, CSS), шёлковый градиент (шейдер интро),
«жидкий» фон, стеклянная линза, желе, частицы (Расширенный). Код:
`src/features/site/motion-gallery.tsx` + `motion-gallery-shaders.ts`,
тест `motion-gallery.test.tsx`. Плитки маленькие (6 в ряд на десктопе),
рендер 1×; в покое — статичный кадр, движение только при наведении (на
телефоне — 3,5 с после касания); с «уменьшить движение» не двигаются.

Пакеты (строки): дизайн (2 / **3 варианта** первого экрана / **3
направления** + исследование), правки (2 по готовой странице / **2 + 2**:
концепция и страница), тексты (редактура или черновик / **продающие** /
**по интервью**), объём (до 7 / до **12** блоков), анимация (появление /
**при прокрутке** / **авторская или 3D**), связь (кнопки / **+ форма** /
**+ квиз, CRM, запись или оплата**), поиск (готов к поисковикам / **добавляем
в Яндекс и Google**), аналитика (— / **базовая** / **поведения** + отчёт),
документы (политика / **+ согласия и cookies**), дизайн-файлы (Figma + гайд
по стилю / … / **дизайн-система лайт**), поддержка (**1 / 2 / 3 месяца**).
Сроки: 5–7 рабочих дней / **1–2 недели** / **2–4 недели**. Базовый —
40 000 ₽, остальные цены — позже. «Во всех пакетах: адаптив · исходный код ·
размещение на хостинге и публикация · замер скорости · работа по договору.
Домен и хостинг оплачиваются отдельно.»

Решения: «Гайд по стилю» = палитра, шрифты, размеры, отступы, скругления
(Базовый, Расширенный); «Дизайн-система лайт» = гайд + набор элементов в
Figma (Максимальный). Варианты дизайна — первые экраны, не целые страницы.
Раунд правок = один собранный список; исправление ошибок — не раунд.

# Что такое cursor rules и как ими пользоваться

Cursor — популярный редактор кода с AI. Чтобы его агент не забывал правила
вашего проекта в каждом новом чате, есть механизм cursor rules: постоянные
инструкции, которые агент получает автоматически.

Правила лежат в папке `.cursor/rules` отдельными файлами и хранятся вместе с
кодом. У каждого правила можно задать, когда оно включается:

- **всегда** — в любой сессии;
- **по файлам** — когда открыт подходящий файл (например, все компоненты);
- **по решению агента** — если правило описано, агент сам поймёт, когда оно к
  месту;
- **вручную** — когда вы явно его позовёте.

Практический совет: общие принципы держите короткими, а узкие правила
привязывайте к конкретным папкам — так агент не перегружается лишним.

Раньше был один общий файл `.cursorrules`, теперь его считают устаревшим и
советуют переходить на папку с правилами.

Формат, примеры и типы правил подробно:
https://ludvik4.dev/blog/cursor-rules

**Пост 1 (хук):**
GitHub осенью 2025 выпустил бесплатный Spec Kit — инструмент, который
заставляет проговорить задачу до того, как AI-агент начнёт писать код.
Разобралась, как он устроен 🧵

**Пост 2:**
1/ Идея: вместо «vibe coding» (описал в чате, принял на глаз) — процесс из
шагов: принципы проекта → спека (что и зачем) → план (как) → задачи →
реализация. Агент сверяется со спекой, а не гадает.

**Пост 3:**
2/ Из чего состоит: CLI `specify` (разворачивает каркас), `constitution.md`
(неизменные принципы), шаблоны команд. Ставится через uv в существующий проект.

**Пост 4:**
3/ Работает с 30+ агентами (Claude Code, Copilot, Codex…), спеки лежат в вашем
репозитории и не привязаны к вендору. Есть альтернатива от AWS — Kiro, но это
уже целый IDE.

**Пост 1 (хук):**
Самый простой способ, чтобы AI-агент перестал нарушать правила проекта, — файл
AGENTS.md в корне репозитория. Это README, но для агента. Собрала шаблон 🧵

**Пост 2:**
1/ Формат радует: обычный Markdown без схемы, заголовки любые. Внутри — обзор
проекта, команды (тесты, сборка), стиль кода и раздел «чего не делать».

**Пост 3:**
2/ Главное правило — коротко. Файл на 400 строк агент «читает», но не
соблюдает: контекст растворяется. Лучше короткая карта + ссылки на детальные
правила.

**Пост 4:**
3/ Один файл понимают десятки инструментов (Codex, Cursor, Copilot…). Для
Claude Code его обычно дублируют как CLAUDE.md — или делают симлинком на один
источник, чтобы не поддерживать копии.

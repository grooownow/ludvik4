# Что такое AGENTS.md и зачем он нужен

Если вы работаете с AI-агентом (Claude Code, Cursor, Codex), у вас наверняка
был момент, когда агент делал что-то мимо правил проекта. Чаще всего причина
одна: он не знает контекста. AGENTS.md — способ этот контекст ему дать.

Это как README, только для агента: файл в корне проекта, который модель читает
в начале каждой сессии. Внутри — то, что нужно, чтобы работать правильно:

- о чём проект и на чём написан;
- какие команды запускать (тесты, сборка);
- как принято писать код;
- чего делать нельзя.

Хорошая новость: формат простой — обычный текст (Markdown), без строгой схемы.
Заголовки любые, порядок любой. Главное правило — держать файл коротким:
длинный документ агент «читает», но плохо соблюдает.

Один и тот же файл понимают десятки инструментов, а для Claude Code его обычно
дублируют под именем CLAUDE.md.

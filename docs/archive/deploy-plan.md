# План деплоя Ludvik4 на Vercel — для Claude Code

> **✅ ВЫПОЛНЕНО (2026-07-15).** Сайт задеплоен и живёт на https://ludvik4.dev
> (Vercel, отдаётся на `www`; apex 308-редиректит на `www`). Репо на GitHub,
> CI зелёный, форма шлёт заявки в Telegram. Этот документ оставлен как справка
> для повторного деплоя / нового окружения. Открытый хвост: сделать apex
> основным доменом, чтобы canonical совпал (см. `docs/roadmap.md` → Next).
>
> Этот сайт — **статический Next.js-лендинг** (без БД и без авторизации).
> Поэтому стандартный `docs/playbooks/deploy.md` (он про приложение с Postgres
> и sign-in) применяется лишь частично: **пропускаем** создание БД, миграции,
> `AUTH_SECRET`, OAuth. Нужны только: GitHub → Vercel → домен → 3 env-переменные.
>
> Формат: **[АГЕНТ]** — делает Claude Code сам; **[ТЫ]** — нужны действия Кати
> (регистрация/клики в вебе, ввод секретов). Агент никогда не просит вставлять
> секреты в чат — только напрямую в Vercel UI.

## Предусловия (проверить до начала)

- **[ТЫ]** Аккаунт GitHub (github.com). Если нет — зарегистрироваться.
- **[ТЫ]** Аккаунт Vercel (vercel.com, вход через GitHub — 1 клик). Если нет — зарегистрироваться.
- **[ТЫ]** Домен `ludvik4.dev` уже куплен (✓ куплен) + доступ к его DNS у регистратора.
- **[АГЕНТ]** Гейты зелёные перед деплоем: `pnpm lint && pnpm test && pnpm build`.
  Никогда не деплоить на красном.
- **[АГЕНТ]** Все правки закоммичены, рабочее дерево чистое (`git status`).

## Шаг 1 — Запушить репозиторий на GitHub

> **Готово.** Репозиторий уже создан и запушен: `github.com/grooownow/ludvik4`,
> ветка `main` актуальна. Этот шаг — только если пушишь заново.

- **[АГЕНТ]** `git remote -v` — есть ли уже remote (есть: `origin` → grooownow/ludvik4).
- **[АГЕНТ]** Проверить `gh auth status`.
  - Если `gh` залогинен → `gh repo create ludvik4 --source=. --private --push`.
  - Если `gh` НЕ залогинен → **[ТЫ]**: выполнить `gh auth login` (или создать пустой
    приватный репо на github.com и дать агенту URL). Затем **[АГЕНТ]**:
    `git remote add origin <url> && git push -u origin main`.
- **⚠ Ловушка авторизации (было при первом пуше):** в `gh` несколько аккаунтов
  (`grooownow` и `ludvik4`), и git-credential может подставить токен НЕ того
  аккаунта → `403 Permission denied to ludvik4`. Репо принадлежит `grooownow`.
  Лечение: `gh auth switch --user grooownow`, либо разовый пуш под нужным токеном:
  `git -c credential.helper= push "https://x-access-token:$(gh auth token --user grooownow)@github.com/grooownow/ludvik4.git" main`
  (токен не сохранять в remote URL).
- **Готово когда:** ветка `main` видна на github.com.

## Шаг 2 — Импортировать проект в Vercel

- **[ТЫ]** vercel.com/new → «Import Git Repository» → выбрать репо `ludvik4`.
  Framework preset определится сам (**Next.js**). Build/Output — по умолчанию.
- **[ТЫ]** НЕ нажимать финальный Deploy до шага 3 (иначе первая сборка будет без
  env — не критично, но лучше сразу с переменными).
- **Готово когда:** проект появился в дашборде Vercel.

## Шаг 3 — Переменные окружения в Vercel

**[ТЫ]** Project → Settings → Environment Variables (scope: Production + Preview).
**[АГЕНТ]** подсказывает значения; секреты Катя вводит сама в Vercel UI.

| Переменная            | Значение                                                          |
| --------------------- | ----------------------------------------------------------------- |
| `NEXT_PUBLIC_APP_URL` | `https://ludvik4.dev` — критично для SEO (canonical, OG, sitemap) |
| `TELEGRAM_BOT_TOKEN`  | тот же токен, что в локальном `.env` (бот заявок)                 |
| `TELEGRAM_CHAT_ID`    | тот же chat_id, что в локальном `.env`                            |

- Опционально позже: `RESEND_API_KEY` / `LEAD_EMAIL_*` (email-доставка),
  `TURNSTILE_*` (капча), `NEXT_PUBLIC_POSTHOG_KEY` (аналитика). Не нужны для запуска.
- **НЕ** ставить `LIFTKIT_DB=remote`, `DATABASE_URL`, `AUTH_*` — БД и авторизации нет.
- **Готово когда:** три переменные заданы, редеплой прошёл.

## Шаг 4 — Первый деплой и смоук-чек

- **[ТЫ]** Нажать Deploy (или Redeploy после добавления env).
- **[АГЕНТ]** дождаться прод-URL (`ludvik4.vercel.app`), затем:
  - `curl -I https://ludvik4.vercel.app/` → ожидать `200`.
  - Проверить, что HTML содержит «Ludvik4», hero, форму.
  - **[ТЫ]** отправить тестовую заявку через форму → проверить, что пришла в Telegram.
- **Готово когда:** 200 + контент + заявка дошла (с доказательствами).

## Шаг 5 — Подключить домен ludvik4.dev

- **[ТЫ]** Vercel → Settings → Domains → Add → `ludvik4.dev` (и при желании
  `www.ludvik4.dev` с редиректом на apex).
- **[ТЫ]** Прописать у регистратора DNS-записи, которые покажет Vercel
  (обычно `A` на apex + `CNAME` на www; или сменить nameservers на Vercel).
  Распространение DNS — от минут до нескольких часов.
- **[АГЕНТ]** когда домен резолвится: `curl -I https://ludvik4.dev/` → `200` по HTTPS
  (сертификат Vercel выдаёт сам). Убедиться, что `NEXT_PUBLIC_APP_URL` уже
  `https://ludvik4.dev` (иначе canonical/OG будут указывать на vercel.app).
- **Готово когда:** `https://ludvik4.dev` отдаёт сайт по HTTPS.

## Шаг 6 — Пост-деплой проверки

- **[АГЕНТ]** Lighthouse спот-чек: `npx lighthouse https://ludvik4.dev --view`
  (или панель в Chrome DevTools). Цель — performance + accessibility ≥ 0.90
  (бюджет из `lighthouserc.js`).
- **[АГЕНТ]** Проверить, что в проде отдаются: `/sitemap.xml`, `/robots.txt`,
  OG-превью (`/opengraph-image`), фавиконка (нет 404 на `/favicon.ico`).
- **[ТЫ, опционально]** Google Search Console: добавить `ludvik4.dev`,
  подтвердить владение, отправить `sitemap.xml` — ускоряет индексацию.
- **Готово когда:** Lighthouse в норме, SEO-файлы отдаются, превью корректны.

## Итог: что нужно именно от Кати

1. Аккаунт **GitHub** (или `gh auth login` локально).
2. Аккаунт **Vercel** + импорт репо (шаг 2).
3. Ввести **3 env-переменные** в Vercel (шаг 3).
4. Добавить домен + **DNS-записи** у регистратора (шаг 5).
5. Отправить одну **тестовую заявку** для проверки (шаг 4).

Всё остальное (пуш, гейты, смоук-чеки, Lighthouse, сверка canonical/OG) — агент.
Тариф Vercel Hobby бесплатен; учесть, что формально он «некоммерческий» — для
сайта услуг на будущее возможен Pro ($20/мес), на старте не блокирует.

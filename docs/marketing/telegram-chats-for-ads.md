Дата: 2026-11-10. Только чтение, без вступлений и сообщений, через рабочий аккаунт @ludvik4work.

Как искали: глобальный поиск Telegram (`contacts.Search`) по 281 запросам (бизнес-чаты, нетворкинг, ниши владельцев бизнеса, фриланс-биржи, география: Дубай, Турция, Грузия, Сербия, Кипр, Таиланд, Бали, Европа, США, города РФ/СНГ). Брали только группы (megagroup) с username, исключали чаты, где уже состоит любой из двух аккаунтов. Нашли 1067 групп. Группы меньше 300 участников и явно нецелевые по названию (вакансии, крипта, психологи, барахолки и т.п.) отсеяли сразу. Остальные 181 проверили по описанию, закрепу и последним 300 сообщениям за 30 дней.

Запросы клиентов считались автоматически (регулярки: «ищу / нужен / кто сделает / посоветуйте» + «сайт / лендинг / бот / разработчик / CRM / автоматизация…»), сообщения исполнителей отфильтрованы, затем топ проверен вручную. Цифры приблизительные. «N за X дн.» значит, что 300 сообщений покрыли только X дней (чат очень активный). «+ M на др. подрядчиков» это запросы дизайнеров, маркетологов, SMM и т.п., то есть заказчики в чате есть.

**Работа не доведена до конца.** После 181 проверенных групп Telegram выдал рабочему аккаунту FloodWait на ~21 час (резолв username). Ещё 444 найденных групп (300+ участников, подходящая по названию) не проверена; их список лежит в scratchpad (`chatsearch/pending.txt`), проверку можно продолжить после снятия лимита. Поэтому в таблице меньше 100 групп, и это не потолок.
